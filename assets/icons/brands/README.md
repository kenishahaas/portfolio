# Brand icon sources

The SVG files in this directory are displayed as single-colour decorative technology marks on the profile page.

- `git.svg`, `linux.svg`, `mysql.svg`, `python.svg`: [Simple Icons](https://simpleicons.org/). Simple Icons is released under CC0; individual brand or icon-specific licences and trademarks continue to apply. The Git icon is distributed under CC BY 3.0.
- `windows.svg`, `microsoft-365.svg`: [Font Awesome Free](https://fontawesome.com/) brand icons, licensed under CC BY 4.0.
- `visual-studio-code.svg`: [Devicon](https://github.com/devicons/devicon), licensed under MIT.

All product names and logos remain the property of their respective owners.
